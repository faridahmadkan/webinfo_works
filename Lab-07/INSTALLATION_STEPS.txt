BOOK REGISTRATION SYSTEM - INSTALLATION

1. Install PHP 8.2+, Composer and XAMPP.
2. Extract the ZIP and open this folder in VS Code.
3. Start Apache and MySQL from the XAMPP Control Panel.
4. Open phpMyAdmin and create a database named book_registration.
5. Run: composer install
6. Copy .env.example to .env and check DB_DATABASE, DB_USERNAME and DB_PASSWORD.
7. Run: php artisan key:generate
8. Run: php artisan migrate
9. Run: php artisan serve
10. Visit http://127.0.0.1:8000/books

The vendor directory is created by Composer and is not included in the ZIP.
